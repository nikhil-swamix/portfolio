# Repository Triage Report

This report summarizes the GitHub repo inventory and how the public portfolio set was chosen.

## Inventory summary

- Total repositories analyzed: **92**
- Public repositories: **71**
- Private repositories: **21**
- Original public projects: **55**
- Public forks: **16**

## Selection criteria

I prioritized projects that are:

1. **Public and portfolio-safe**
2. **Original work**, not just forks of upstream projects
3. **Technically credible** and easy to understand from the repository description
4. **Supported by measurable signals** such as stars, forks, commits, and code size
5. **Relevant to hiring / client work**, especially tooling, AI, infrastructure, and developer productivity

## Notable excluded categories

### Private or client work
Private and client-specific repos were reviewed locally but omitted from the public portfolio.

### External forks / mirrors
Forks of upstream projects were not treated as core portfolio pieces unless they represented an important contribution.

### Non-portfolio-safe repos
Some repos were better left out of the public showcase because they are not representative of a professional portfolio or because they focus on activity automation / bot-style tooling.
